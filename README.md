# خوش حساب — Android

اپلیکیشن Native اندروید با Kotlin، Jetpack Compose، Retrofit و Material 3.

## باز کردن در Android Studio

1. در Android Studio گزینه **Open** را بزنید.
2. پوشه `android-app` را انتخاب کنید.
3. JDK پروژه را روی Embedded JDK 17 یا جدیدتر قرار دهید.
4. اجازه دهید Gradle Sync و نصب Android SDK 36 کامل شود.
5. Repository بک‌اند را جداگانه دریافت و از پوشه آن اجرا کنید:

   ```bash
   docker compose up -d
   ```

6. یک Emulator اجرا و سپس Run را بزنید.

## آدرس API

آدرس پیش‌فرض برای Android Emulator:

```text
http://10.0.2.2:8000/api/
```

در صورت تست روی گوشی واقعی، مقدار `API_BASE_URL` در
`app/build.gradle.kts` را به IP کامپیوتر در شبکه محلی تغییر دهید؛ برای مثال:

```text
http://192.168.1.10:8000/api/
```

گوشی و کامپیوتر باید به یک شبکه متصل باشند و پورت 8000 در فایروال باز باشد.

## قابلیت‌ها

- ورود، ثبت‌نام و بازیابی رمز
- OTP هفت‌رقمی راه‌پیام با تایمر پایدار ۱۲۰ ثانیه‌ای
- ایجاد گروه، عضویت با کد و بررسی درخواست‌ها
- دنگ و حساب بلندمدت
- ثبت و تقسیم مساوی هزینه
- مانده اعضا و تسویه
- چت گروهی و استیکر
- اعلان‌های عضویت و تسویه
- پروفایل، ایمیل اختیاری و تغییر شماره با OTP

چت فعلی هر پنج ثانیه از API بروزرسانی می‌شود. برای Push بلادرنگ باید در مرحله
بعد Laravel Reverb/WebSocket به بک‌اند و اپ اضافه شود.
